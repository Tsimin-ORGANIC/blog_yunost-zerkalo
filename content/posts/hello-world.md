这是本档案室的第一份卷宗，用来试试排版，也算一纸开工公文。

钇（Y）与锆（Zr）是元素周期表里的两个符号；「拾遗」是补录那些差点散佚的片段。三个字合在一起，谐音「忆·告·拾遗」——把记忆归档，把遗失的重新钉回墙上。俄语名字 **Юность Зеркало**（青春之镜）盖在每一份卷宗的扉页上，编号 Y-Zr。

以后这里大概会归档三类东西：**摘录与批注**（读到的史料、画册、旧物）、**看展记录**（博物馆和美术馆的传阅件），还有一些随手钉住的黄昏与铁轨。

## 卷宗怎么写

每份卷宗就是一个 Markdown 文件，放进 `content/posts/` 即可。文件开头用这样一段「登记信息」来设置标题、标签等：

```yaml
---
title: 卷宗标题
date: 2026-06-05T17:23:53+08:00
description: 一句话摘要（会显示在列表页和分享卡片上）
tags: [旧物, 铁轨]
categories: [摘录与批注]
draft: false   # 写完记得改成 false 才会移交上架
---
```

## 怎么插图（最常用的功能）

档案室离不开照片。推荐用「页面文件夹」的方式管理：给卷宗建一个同名文件夹，把 Markdown 改名成 `index.md`，图片放在旁边，比如：

```
content/posts/观展记录-某博物馆/
├── index.md        ← 卷宗正文
├── cover.jpg       ← 登记照（登记信息里写 cover: cover.jpg）
└── img/
    ├── 1.jpg
    └── 2.jpg
```

正文里用 Hugo 自带的 figure 短代码插图，自带图注和编号感：

也可以写代码块、引用和列表，Markdown 的常规语法都支持：

> 「档案不是过去本身，而是过去遗留在值班桌上的那盏没关的灯。」
>
> —— 库房值班员手记，编号 Y-Zr-000

| 常用语法 | 效果 |
| --- | --- |
| `**加粗**` | **加粗** |
| `*斜体*` | *斜体* |
| `[链接](https://gohugo.io)` | [链接](https://gohugo.io) |

写完在本地跑 `hugo server` 预览，满意后再提交推送，GitHub Actions 会自动上架。
